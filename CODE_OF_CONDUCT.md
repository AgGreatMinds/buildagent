# Código de conduta

Este projeto segue o [Contributor Covenant 2.1](https://www.contributor-covenant.org/pt-br/version/2/1/code_of_conduct/).

Em resumo: trate as pessoas com respeito, critique o código e não quem escreveu, e aceite que gente com
experiências diferentes vai discordar de você. Assédio, ofensa e exposição de dado pessoal de terceiros
não são tolerados em issues, pull requests ou qualquer espaço do projeto.

Para relatar um problema de conduta, fale com quem mantém o repositório pelo aviso privado do GitHub
(o mesmo canal descrito em [SECURITY.md](SECURITY.md)). Relatos são tratados com sigilo.
